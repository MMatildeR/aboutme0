## Publicar en GitHub Pages
1. Copiá estos archivos a la raíz de tu repo `IDCARD` (o el que uses), reemplazando los actuales.
2. Poné tu foto en `IMG/FotoCV.png`.
3. Hacé commit y push a la rama que tenga habilitado GitHub Pages (normalmente `main`).
4. En unos minutos los cambios van a estar en tu URL de siempre.
